# Optional scientific falsification lane

Status: experimental and opt-in. Base: `1193059aecb0e2ff00070c109f64fd1465b62f9c`.

Ares orchestrates checks; it does not own mathematical truth, canonical evidence semantics, support admission, or a new execution authority. The concrete consumers are the Libraries constitutive-witness kernel and ClaimLedger scientific-evidence CLI.

## Incremental delivery

1. Add an optional `falsify` skill with source-first contract extraction and cheapest-first checks. No core tool, prompt mutation, or default installation.
2. Add a bounded local runner for explicitly selected scientific checks. Plans are data, not arbitrary executable commands. Inputs, backend identities, stdout/stderr, exit states, and outputs are recorded.
3. Validate evidence through ClaimLedger rather than trusting backend JSON. Missing dependencies and failed/timeout checks remain explicit; no synthesized pass.
4. Add deterministic planning, negative tests, filesystem/output safeguards, subprocess/resource limits, and reproduction instructions.
5. Link the Libraries and ClaimLedger PRs and record the required integration/CI gates.

## Required semantics

- `not_refuted` does not mean `true` or `supported`.
- Arbitrary documents never become shell commands.
- No model/provider calls, network access, paid compute, live runtime activation, ledger mutation, or publication is performed by the bounded runner.
- User explicitly selects input files and installed trusted backends. Whole-process sandboxing remains the OS/operator responsibility; a receipt is not containment.
- Hashes bind bytes, not truth. Formal proof and continuum claims require independent verification.
- The historical conditional transported-viscosity proof remains unreviewed; no OpenAI/Clay breakthrough claim is required or promoted.

## Follow-on work

Provider-assisted research panels, backend admission to a live profile, additional scientific methods, a larger FalsifyBench, and publication of mathematics are tracked future gates, not implied by this skill.

## Rollback

Remove the optional skill or revert this branch's additive commits. No existing core tools, session cache, runtime selection, persistent claims, or permissions change.
